What is the difference between ArrayList and LinkedList?

Answer:

ArrayList uses a dynamic array internally.
LinkedList uses a doubly linked list.
ArrayList is faster for searching and reading.
LinkedList is faster for insertion and deletion in the middle.
What is the difference between HashSet and HashMap?

Answer:

HashSet stores only unique values.
HashMap stores key-value pairs.
HashSet internally uses HashMap.
What happens if two objects have the same hashCode?

Answer: Both objects will be stored in the same bucket. HashMap uses equals() to distinguish between them.

What is the difference between checked and unchecked exceptions?

Answer:

Checked Exceptions are checked at compile time (IOException, SQLException).
Unchecked Exceptions occur at runtime (NullPointerException, ArithmeticException).
